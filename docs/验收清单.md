## 1. 文档目标

- 对`执行计划.md`中的M1/M2/M3/M4里程碑任务逐项验收
- 保留已通过的P0/P1验收项（底座能力），更新P2为全栈验收
- 所有验收项必须有任务映射、证据、回归测试结果
- 验收结论分为：`通过` / `有条件通过` / `不通过` / `后端通过`（后端完成但前端/协议未闭环）

## 2. 验收规则

- 每条验收项绑定唯一编号（`ACPT-M<milestone>-<seq>`）
- 每条验收项绑定执行计划中的任务编号（`TASK-M1-xxx`）
- 每条验收项至少1条证据
- 每条验收项至少1条回归测试覆盖
- **证据类型**：
  - `E1` 页面截图/UI交互
  - `E2` 接口响应（panel RPC返回值）
  - `E3` 协议报文/日志（Erlang lager日志、Protobuf帧）
  - `E4` 自动化测试报告（eunit/go test/e2e）
  - `E5` 录屏或操作录像
  - `E6` 配置/数据快照（Mnesia表内容、文件快照）
